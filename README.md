# ivec-ux-quiz-web

[IVEC UX評価スペシャリスト クイズ](https://github.com/sazanamix/ivec-ux-quiz) のWeb版（Blazor WebAssembly）を、GitHub Pagesで公開するための**ビルド済み静的ファイル専用リポジトリ**です。

## 公開URL

https://sazanamix.github.io/ivec-ux-quiz-web/

iPad等のSafariで開き、共有メニューから「ホーム画面に追加」するとアプリのように利用できます。

## このリポジトリについて

- ソースコード（Blazorプロジェクト・問題集原稿など）はここには含まれません。すべて [sazanamix/ivec-ux-quiz](https://github.com/sazanamix/ivec-ux-quiz)（Private）で管理しています。
- このリポジトリの中身は `dotnet publish` で生成した `wwwroot` の中身をそのまま置いたものです。**直接編集しないでください**（更新する場合は元リポジトリ側でビルドし直して再度pushします）。
